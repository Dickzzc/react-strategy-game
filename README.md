# React Strategy Game

这是一个在浏览器运行的类《红色警戒 2》风格的即时战略游戏 Demo，由 React 和 HTML5 Canvas 构建。游戏采用俯视 2D 视角，玩家与 AI 阵营各自操控基地、建造建筑、生产军队并展开战斗。本项目示范了基本的建造系统、多单位操控、简单 AI 行为以及存档/读档功能。

## 运行方式

项目使用 [Vite](https://vitejs.dev/) 作为开发服务器和打包工具。要在本地启动开发模式，请执行：

```bash
npm install
npm run dev
```

随后在浏览器访问 http://localhost:5173 即可进入游戏界面。你可以修改代码并实时查看效果。

构建生产环境版本使用：

```bash
npm run build
```

构建完成的文件会输出到 `dist/` 目录，可以部署到任何静态文件服务器。

## 核心功能

- **地图与渲染**：使用 Canvas 2D 渲染 50×50 的网格地图，草地、道路、水域等元素通过程序化方式绘制。所有单位和建筑用几何图形和颜色表示。
- **阵营与单位**：玩家（蓝色）与 AI（红色）分别拥有基地、兵营、战车工厂、发电厂等建筑，可生产步兵、轻型坦克、重型坦克等单位。
- **建造系统**：点击建筑打开建造菜单，选择建筑后在地图上放置。建筑有建造时间，需要空地且不允许重叠。建筑完成后可以生产单位。
- **单位操控**：鼠标左键选中单位/建筑，拖拽框选可多选；右键点击地面进行移动，右键点击敌方进行攻击。支持快捷键暂停/继续游戏。
- **AI 系统**：AI 会自动收集资源、建造发电厂/兵营/战车工厂，训练军队并在达到一定规模后向玩家基地发起进攻。
- **存档系统**：按 UI 按钮可将当前游戏状态保存到 LocalStorage 中的三个槽位之一，刷新页面后可读取保存的进度继续游戏。

## 注意事项

由于这是一个 Demo 项目，许多规则和数值经过简化调整，单位行为也较为粗略（例如不包含复杂的寻路算法）。欢迎在此基础上自由扩展和优化。
